# Investment Portfolio Tracker

A terminal-based portfolio tracker written in Python 3 using the standard library only (`csv`, `os`, `datetime`).

## Features

- Enter stock ticker symbols, buy prices and share quantities.
- Tickers are validated against the S&P 500 dataset (`constituents.csv`), and the company name is shown in the output.
- Positions are stored in a dictionary. Buying the same ticker again merges into one holding at a weighted average buy price.
- Calculates total invested capital, current market value, and the gain/loss and % gain/loss for each holding.
- Prints a formatted table to the console.
- Saves the results to `portfolio_summary.csv` using Python's built-in `csv` module.

## Folder structure

```
portfolio/
├── portfolio.py            # the program
├── constituents.csv        # S&P 500 ticker dataset
├── sample_prices.csv       # sample current prices
├── portfolio_summary.csv   # output generated by the program
└── README.md               # this file
```

## How to run

1. Install Python 3 from https://www.python.org/downloads/
2. Open a terminal in the `portfolio` folder.
3. Run:

```
python portfolio.py
```

## How to use

1. Choose `1` to add a holding: enter the ticker (e.g. `AAPL`), the buy price per share, and the number of shares.
2. Choose `2` to view the portfolio summary table.
3. Choose `3` to save the summary to `portfolio_summary.csv` and quit, or `4` to quit without saving.

## About the prices

Current prices are read from `sample_prices.csv`. These are **illustrative sample prices, not real market data**. If a ticker has no sample price, the program asks you to type its current price.

For live prices, install yfinance and run with the `--live` flag:

```
pip install yfinance
python portfolio.py --live
```

If a live price cannot be fetched, the program falls back to the sample price.

## Output

`portfolio_summary.csv` contains one row per holding (timestamp, ticker, company, shares, buy price, current price, invested, market value, gain/loss, gain/loss %) and a final TOTAL row. The file is overwritten each time you save.
